# BankingApp

**BankingApp** is a learning project created to practice the basics of **synchronization and multithreading** using Windows Forms.

The project also uses **Entity Framework** to practice working with a database and connecting it to a visual user interface.

This is **not a real or fully functional banking application**. It is a small educational project created for practice and experimentation with databases, graphical interfaces, multithreading, and synchronization.
